1. Fundamentos del lenguaje

¿Qué es JavaScript y cómo evolucionó?

Propiedades técnicas esenciales

  • Compilación JIT: lenguaje de alto nivel interpretado y compilado en tiempo de ejecución (Just-In-Time) para lograr alta velocidad.
  • Tipado dinámico: las variables se adaptan al tipo de dato asignado en ejecución sin ataduras rígidas.
  • Multiparadigma: combina programación orientada a objetos, imperativa y funcional según la necesidad.
  • Norma ECMAScript: estándar internacional que asegura compatibilidad entre navegadores y evolución continua en seguridad y sintaxis.
1995 · Brendan Eich

Nace para dar dinamismo inmediato a páginas estáticas que solo mostraban texto e imágenes fijas.

Estándar ES6+

Incorpora alcance de bloque (let / const), promesas y sintaxis moderna limpia.

Actualidad

Motor lógico universal en navegadores, servidores HTTP, móviles y escritorio.

Dato clave: JavaScript es independiente de Java: fue creado en 1995 para la web y hoy evoluciona bajo la especificación internacional ECMAScript.

3.2 Representación en memoria RAM

Nodo seleccionado: document

Es el punto de comunicación dinámica entre JavaScript y el árbol de etiquetas en memoria.

// Localizar un elemento sin recargar

4.1 Ciclo de vida en memoria

El Scope y diferencias entre var, let y const

Prueba cada declarador y nivel
Palabra Alcance Reasignable Uso
var Función (ignora { }) Sí Evitar fugas.
let Bloque { ... } Sí contador, saldo.
const Bloque { ... } No Por defecto / DOM.
Simulador en bloque if: 
if (true) {
  let saldo = 500;
  saldo = 300; // Reasignación dentro
}
console.log(saldo); // Lectura fuera del if
Dentro del bloque: Ahora vale 300 (reasignable).
Fuera del if: Protegida (ReferenceError).

Cadena de Alcance: ¿desde dónde lees?

Visible
let contador = 0;
Visible
function mostrarSaludo(tipo)
Leyendo aquí
const oculto = true;
Desde el Bloque { }: la cadena sube y accede a los 3 niveles (oculto, tipo y contador).
Dato clave: Scope Chain: JavaScript busca variables desde el bloque interno hacia afuera; con let y const nada se filtra fuera de su { }.

Palabras reservadas esenciales

Declara una función asíncrona sin bloquear el hilo.

awaitAsincronía

Pausa la función interna hasta resolver la promesa.

Instancia un objeto como new Promise.

try / catchErrores

Captura fallos en ejecución sin detener el sistema.

Valores lógicos booleanos para decisiones y estados.

Ausencia intencional de valor asignada por código.

undefinedValores

Variable declarada que aún no tiene ningún dato.

Dato clave: Las palabras reservadas forman la gramática fija del motor JavaScript y no pueden utilizarse como nombres de variables o funciones propias.
4.3 Estructura y pertenencia

Funciones, Métodos y Callbacks del DOM

Función Autónoma

Bloque independiente declarado con function o flecha () => {}. Existe por sí sola.

Método de Objeto

Pertenece a un objeto, se invoca con punto (cuenta.depositar(100)) y opera sus datos mediante this.

Callback

Rutina pasada como argumento a otro método para diferir su ejecución, como en addEventListener("click", fn).

Método del DOM / JS Función práctica
getElementById("id") Localiza y retorna un nodo HTML por su identificador único.
addEventListener(ev, fn) Escucha clics ("click") o teclas ("keydown").
classList.toggle("clase") Agrega o quita una clase CSS devolviendo un booleano.
trim() Limpia espacios en blanco al inicio y final de textos.
setAttribute() / removeAttribute() Actualiza o retira atributos ARIA (aria-expanded, aria-busy).
Dato clave: Toda función que vive dentro de un objeto se llama método y accede a las propiedades de ese objeto mediante la palabra reservada this.
4.4 Modelo Single-Threaded y Event Loop

Funciones Síncronas vs. Asíncronas

Simulador de hilo principal (1,5 s de espera de red)

Compara cómo responde la interfaz cuando una tarea bloquea el hilo frente a delegarla con async / await:

Interfaz lista y respondiendo en el hilo principal.

1. Pendiente (Pending)

Petición en espera sin bloquear la pantalla del usuario.

2. Cumplida (Fulfilled)

Operación exitosa retomada justo después de await.

3. Rechazada (Rejected)

Fallo controlado mediante bloques try / catch.

Dato clave: El Event Loop permite que JavaScript pause únicamente la función que espera una respuesta del servidor sin congelar el resto del navegador.
5. Más allá del navegador

El salto al servidor con Node.js y Bun

En 2009 Ryan Dahl extrajo el motor V8 fuera del aislamiento del navegador (sandbox) para gobernar archivos, redes y bases de datos en el servidor.

Criterio Técnico Node.js (2009 · Ryan Dahl) Bun / Bun.js (2023 · Jarred Sumner)
Naturaleza Entorno de ejecución (runtime) multiplataforma fuera del navegador. Runtime de nueva generación compatible con proyectos Node.js.
Motor y Lenguaje Base Motor V8 de Google programado sobre C++. Motor JavaScriptCore (Apple) escrito desde cero en Zig.
Arquitectura y Velocidad Non-blocking I/O: miles de conexiones con poca memoria RAM. Tiempos de arranque hasta 4 veces más rápidos.
Herramientas (Tooling) Gestor NPM (el mayor ecosistema del mundo) + utilidades externas. Kit Todo en Uno (run, install, test, empaquetador).
Soporte TypeScript Requiere configuración o transpilación en su forma clásica. Ejecución nativa directa de archivos .ts de fábrica.
Dato clave: Node.js no es un nuevo lenguaje ni un framework: es el entorno que abrió el camino a JavaScript en el backend, optimizado hoy por alternativas como Bun.

btnSaludar.addEventListener("click", () => {

Bloque 4: Validación de Pago Móvil asíncrono

Simulación en vivo ($500)

4. Validación de Pago Móvil

Saldo disponible en cuenta $500

1. Validación síncrona 2. Espera await (1 s) 3. Saldo actualizado 
btnTransferir.addEventListener("click", async () => {
  const monto = Number(inputMonto.value);
  if (monto <= 0 || isNaN(monto)) return;
  if (monto > saldoDisponible) return;

  btnTransferir.disabled = true;
  btnTransferir.setAttribute("aria-busy", "true");
  await new Promise(r => setTimeout(r, 1000));

  saldoDisponible -= monto;
  textoSaldo.textContent = saldoDisponible;
  btnTransferir.disabled = false;
  btnTransferir.removeAttribute("aria-busy");
});
Dato clave: Deshabilitar el botón durante el await evita cobros duplicados por doble clic mientras el servidor responde en segundo plano.
7. Síntesis técnica

Conclusiones

JavaScript transforma documentos estáticos en aplicaciones dinámicas en el cliente y escala hacia el servidor moderno con Node.js y Bun.

Interactividad Cliente

Valida entradas y responde sobre el árbol DOM sin recargas innecesarias, optimizando recursos del servidor.

Fluidez Asíncrona

Dominar let/const, eventos y flujos async / await evita congelar la interfaz del usuario.

Visión Full-Stack

Comprender tanto el esquema clásico con PHP como Node.js y Bun aporta una formación web completa.
